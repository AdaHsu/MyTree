# MyTree

> **Language**: **繁體中文** | [English](README.en.md)

輕量級 Windows 命令列目錄樹檢視與檔案整理工具（單一 C# 原始檔、零第三方相依性）。
除了標準目錄樹外，支援**時間軸樹（按修改年月/日期歸納）**、**重覆檔名自動識別與清理指令檔生成（`-dup` / `-dc` / `-c`）**、**目錄與檔案層數分離控制**、**開發者常用群組與萬用字元/正則表達式過濾**，以及**多語系與外部 `.lang` 語系檔擴充**。

## 為什麼有這個工具？

1. **展示檔案組成結構**：有時候需要列印出清楚的樹狀目錄圖，用來在文件或討論中表示專案與檔案的組成架構。
2. **突破內建 `tree` 的限制**：Windows 內建的 `tree` 指令只能選擇「全印」或「全不印」檔案名稱，但專案中遇到龐大的第三方函式庫（如 `node_modules`、`.git`、`bin`/`obj`）或深層目錄時，通常不會想全部印出來洗版——因此設計了群組排除（`-eg`）、自訂條件過濾（`-e` / `-i`）以及目錄與檔案層數分離控制（`-L` / `-fL`）。
3. **解決磁碟空間不足與重覆檔案清理**：在遇到系統碟空間不足、需要整理與刪除檔案時，為了快速找出散落各處的同名檔案與下載副本（如 `(1)`、`- 複製`），進而加入了**重覆檔案檢測（`-dup`）**與**安全刪除指令檔生成（`-dc` 留最新刪舊檔 / `-c` 指定系列全數清理）**功能。

## 編譯方式

無須安裝 Visual Studio 或龐大的 SDK，直接使用 Windows 內建的 .NET Framework 編譯器即可編譯為單一執行檔：

```powershell
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /optimize+ /out:MyTree.exe MyTree.cs
```

## 快速上手

```powershell
# 檢視當前目錄（預設自動排除 .git, .vs, .vscode, .idea，並自動標示 "(重覆)" 檔名）
MyTree

# 以「重覆檔名」為主，展開各同名檔案（含 (1)、- 複製、- Copy 副本）散落的目錄樹
MyTree -dup -t -s

# 【重覆清理 -dc】排除不需排查的目錄後，針對重覆檔案產生 clean_<目錄名>.txt（每組保留最新 1 個，其餘產生 del）
MyTree -e backup,archive -dup -dc

# 【全數清理 -c】用 -i 篩選出特定檔案系列（支援正則 /.../ 或萬用字元 *），將符合的檔案全部寫入 clean_<目錄名>.txt 刪除（不保留）
MyTree -i "/^P\d+\.png$/" -c
MyTree -i "ChatGPT Image*.png" -L 1 -t -c

# 結合時間軸樹與重覆檔案過濾：檢視同名檔案在不同日期的散落位置
MyTree -dt -dup

# 展開 4 層目錄，但只列出前 2 層內的檔案，並顯示異動時間與檔案大小
MyTree -L 4 -fL 2 -t -s

# 以「年月 -> 日」時間軸歸納檔案異動
MyTree -dt

# 排除 node 與 python 常見快取/套件目錄，且只顯示程式碼檔案
MyTree -eg node,py -ig code

# 匯出英文語系範本至 <執行檔名>.lang 供自訂翻譯其他語言
MyTree -el
```

## 參數說明

| 參數 | 說明 |
| :--- | :--- |
| `-L <層數>` | 限制顯示的目錄深度（例如 `-L 5`） |
| `-fL <層數>` | 限制顯示檔案的深度（預設同 `-L`，需 `<= -L`） |
| `-dt`, `--date-tree` | 以「年月(`YYYYMM`) -> 日(`DD`)」作為根層級歸納檔案 |
| `-mt`, `--month-tree` | 以「年月(`YYYYMM`)」作為根層級歸納檔案 |
| `-dup`, `--duplicates` | 以「重覆檔名」為根層級，展開其散落的目錄樹（自動將 `(1)`、`- 複製`、`- Copy` 視為同組，並同步支援 `-dt` / `-mt`） |
| `-dc`, `--dup-clean` | 針對檢視範圍內的**重覆檔案**產生清理清單 `clean_<目錄名>.txt`（**每組保留最新 1 個**，其餘產生 `del` 指令） |
| `-c`, `--clean` | 針對檢視範圍內**所有符合條件的檔案**產生清理清單 `clean_<目錄名>.txt`（**全部產生 `del` 指令、不保留**，常搭配 `-i` 清除特定檔名系列） |
| `-d` | 只顯示目錄，不顯示檔案（等同於 `-fL 0`） |
| `-a` | 顯示隱藏檔案與目錄 |
| `-t`, `--time` | 顯示檔案最後異動時間（格式：`yyyy-MM-dd HH:mm`） |
| `-s` | 顯示檔案大小（若與 `-t` 同時使用，先顯示時間再顯示大小） |
| `-o <檔名>` | 將結果匯出至檔案（UTF-8，自動移除顏色碼） |
| `-e`, `--exclude <規則>` | 排除指定的目錄或檔案（支援副檔名、完整名稱、`*`/`?` 萬用字元、`/.../` 正則） |
| `-eg <群組名>` | 套用排除群組（內建：`git`, `ide`, `node`, `py`, `dotnet`, `java`, `cpp`） |
| `-i`, `--include <規則>` | 只顯示符合的檔案（支援副檔名、完整名稱、`*`/`?` 萬用字元、`/.../` 正則；自動隱藏不含目標檔案的空目錄分支） |
| `-ig <群組名>` | 套用包含群組（內建：`node`, `py`, `dotnet`, `java`, `cpp`, `code`, `doc`, `media`, `config`, `test`） |
| `--no-default` | 停用預設自動排除的群組（`git`, `ide`） |
| `--groups` | 查看目前生效的設定檔路徑、生效語系與所有群組清單 |
| `-l`, `--lang <語系\|檔名>` | 指定內建語系（`en` \| `zh-TW`），或直接傳入任意自訂 `.lang` 語系檔路徑（如 `-l ja.lang`） |
| `-el`, `--export-lang` | 將英文語系範本輸出至與執行檔同名的 `<執行檔名>.lang` |
| `-h`, `--help` | 顯示說明訊息 |

## 設定檔 (`<執行檔名>.ini`) 與自訂語系檔 (`<執行檔名>.lang`)

程式會**動態偵測執行檔本身的名稱**來對應設定檔與語系檔（例如執行檔為 `MyTree.exe` 時對應 `MyTree.ini` 與 `MyTree.lang`；若你將執行檔改名為 `mt.exe`，則自動對應 `mt.ini` 與 `mt.lang`）：

1. **`<執行檔名>.ini` 設定檔**：
   - 首次執行時，若執行檔所在目錄沒有對應的 `.ini`，程式會自動產生預設設定檔（工作目錄優先，否則讀取執行檔所在目錄）。
   - 可於設定檔中自訂 `[Defaults]`（含 `Language = auto | zh-TW | en`、`ShowTime`、`DupOnly`）、`[Colors]`（終端機配色，含 `Time`、`Duplicate`）、`[ExcludeGroups]` 與 `[IncludeGroups]`。
2. **`<執行檔名>.lang` 多語系擴充**：
   - **內建語系**：內建 `zh-TW`（繁體中文）與 `en`（英文），預設依系統語系自動切換。
   - **匯出範本**：執行 `MyTree -el`（或 `--export-lang`）會在執行檔目錄下產生與執行檔同名的 `<執行檔名>.lang` 英文範本。
   - **套用自訂語系**：
     - **自動載入**：只要將翻譯好的 `<執行檔名>.lang` 放在當前工作目錄或執行檔所在目錄下，啟動時即自動載入覆蓋。
     - **手動指定**：也可透過 `-l <檔案路徑>`（例如 `MyTree -l D:\lang\ja.lang`）指定任意名稱的語系檔。
     - 保留字串中的 `{0}`, `{1}` 等參數佔位符即可依各國語法自由調整語序；連同 `CopySuffixWords`（系統複製尾綴字詞）亦可隨語系自訂擴充。
